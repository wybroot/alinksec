# Globe land geometry

`land.json` contains rounded coastline coordinates and precomputed land dots derived from Natural Earth 1:110m physical land polygons. Runtime rendering uses bundled local geometry and never requests a map service.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Source SHA256: `9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`
- Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
- Land outlines are decorative. Event paths are schematic and carry no geographic attribution.
