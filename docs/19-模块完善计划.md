# 模块完善计划

开发按模块顺序推进：一个功能模块对应一条分支，分支必须从已合并并通过检查的最新 `main` 创建。在该分支完成实现、系统适配、异常处理、安全边界和验证后再整理 PR；验收完成即按用户既定授权合并到 `main`，核对合并后的源码及检查结果，同步本地 `main`，然后开始下一个模块。不得以尚未合并的功能模块分支作为下一模块的基础。版本发布与实际部署仍须单独指示。
