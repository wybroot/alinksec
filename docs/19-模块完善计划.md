# 模块完善计划

开发按模块顺序推进：一个功能模块对应一条分支，在该分支完成实现、系统适配、异常处理和验证后，再整理 PR。模块的 PR 在实现和验收完成后转为可审阅；合并和新版本发布按用户指示安排。
