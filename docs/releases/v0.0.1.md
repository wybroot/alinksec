# ALinkSec v0.0.1

首次开发阶段发布，统一服务端、Web 和 Agent 产品版本为 `0.0.1`。

项目默认 README 为英文，`README-cn.md` 提供中文，两版顶部可相互跳转。

## 功能

- 主机注册、gRPC mTLS、心跳及软件/进程/账户/端口/磁盘资产。
- 基线核查与修复，漏洞、弱口令和高危端口扫描，软件包审批与维护窗口。
- 病毒扫描与处置、白名单及特征库热更新，进程行为与勒索诱饵检测。
- Linux 文件完整性与 SSH 登录防护，主机隔离与恢复、指令 ACK 和重启后的离线补传。
- Agent 原生常驻、成品更新和授权卸载，Webhook、审计、RBAC、控制台与安全大屏。
- PostgreSQL + VictoriaMetrics 和 SQLite 单实例轻量部署，SQLite 在线备份、完整性校验及恢复。

## 部署与下载

server/web 使用 Linux amd64 容器；受控主机原生安装 Linux amd64 或 Windows amd64 Agent。轻量模式只有 server/web 两个长期容器，SQLite 维护工具按需运行。

```text
wangyanbiao/alinksec:server-v0.0.1
wangyanbiao/alinksec:web-v0.0.1
wangyanbiao/alinksec:sqlite-maintenance-v0.0.1
```

附件包括完整源码/部署/文档包 `alinksec-v0.0.1.tar.gz`、两个原生 Agent、`SHA256SUMS` 与 `release-manifest.json`。校验文件记录附件 SHA256，manifest 记录发布提交、完整 CI run ID 和三种镜像的 digest。完整安装步骤见 [部署文档](https://github.com/wybroot/alinksec/blob/v0.0.1/docs/06-部署文档.md)，发布机制见 [发布流程](https://github.com/wybroot/alinksec/blob/v0.0.1/docs/13-版本发布流程.md)。

## 验收范围

Linux 功能链路、PostgreSQL/SQLite 全新部署、桌面/移动浏览器与本机原生 Agent 已验收。原生 Linux Agent 在约 2 GiB 主机的 197 秒采样中，空闲 CPU 平均约单核 0.80%，空闲 RSS 约 20 MiB，含采集子进程的 RSS 峰值 47.48 MiB；这是短时采样，不能代替全盘扫描、字典任务或规模压测。

Windows 原生成品已在 Windows Server 2025 的实际 SCM 中验证 mTLS、真实资产、采集 ACK、停止/启动及自动恢复；协议端使用 TLS fixture，该结果不代表 Windows 全量安全引擎与 Java 平台完整联动。Linux 文件/SSH 防护能力的实测结论仅适用于 Linux。SQLite 边界为 1～10 台、单 server、本机持久化卷，默认关闭指标，无高可用保证。100～2000 台属于设计规模目标，尚无相应规模验收结论。

来源网段、端口绑定、证书接入地址和资源配额按交付环境设置。请使用独立的强初始凭据、持久化数据卷与平台 CA，按实际主机需求启用主动响应。当前缺陷清单无 OPEN/VERIFY。
