## 平台与六个附件

Server、Web、SQLite 维护镜像均为 Linux amd64 + arm64；原生 Agent 为 Linux amd64、Linux arm64、Windows amd64。

```text
wangyanbiao/alinksec:server-v0.0.3
wangyanbiao/alinksec:web-v0.0.3
wangyanbiao/alinksec:sqlite-maintenance-v0.0.3
```

| 附件 | 用途 |
| --- | --- |
| `alinksec-v0.0.3.tar.gz` | 完整源码、部署配置、中英文 README 与文档 |
| `alinksec-agent-linux-amd64` | Linux x86_64 Agent |
| `alinksec-agent-linux-arm64` | Linux aarch64 Agent |
| `alinksec-agent-windows-amd64.exe` | Windows x64 Agent，来自 Windows Server 2025 的成功原生作业 |
| `release-manifest.json` | 精确源码提交、完整 CI run ID、各附件 SHA256、镜像索引及两个平台 digest |
| `SHA256SUMS` | 其他五个附件的 SHA256 |

Windows Server 2022 仍须通过完整原生回归；其独立 Agent 产物保留在 CI 中，不参与发布附件的同名合并。两个 Linux Agent 分别来自对应架构实际执行过的 CI 成品。正式发布另行构建并冒烟验证真实镜像，再按不可变 digest 合并双架构索引。

三个默认 Agent 附件采用 `CGO_ENABLED=0` 构建，未包含原生 YARA 运行时。使用 YARA 需按[原生 YARA 说明](../65-原生YARA引擎与规则证据.md)启用 `nativeyara` 构建并配置本机规则；默认附件会明确报告该引擎未支持。ClamAV 也需部署环境配置和维护本机服务，具体配置见[ClamAV 引擎](../64-ClamAV引擎与扫描证据.md)。

发布成功后下载全部六个附件，执行 `sha256sum --check SHA256SUMS`，再按[部署文档](../06-部署文档.md)安装。校验版本、源码和镜像 digest，切勿混用 v0.0.2 文件与 v0.0.3 Compose。

## 数据库与部署

相对 v0.0.2 新增迁移 `V002` 至 `V036`。SQLite 在应用启动时自动应用对应迁移；PostgreSQL 先使用随包迁移入口完成 schema 与最小权限设置，再启动新版 server。部署命令、凭据、证书和备份顺序以[部署文档](../06-部署文档.md)和[检查清单](../../deploy/部署检查清单.md)为准，不修改已应用的迁移文件。

当前交付范围为全新部署。真实历史生产数据库升级因没有对应存量环境不适用；模拟迁移、幂等、回滚和恢复回归保留。已有环境升级前需另行建立实际备份和升级演练证据，不将本版本 CI 作为该结论。

SQLite 维持单 server、本机持久化卷；多副本使用 PostgreSQL 和[集群配置](../../deploy/cluster/README.md)。多副本本身不证明数据库、消息服务或存储的完整高可用，依赖应按部署环境另行配置。

## 验证与现场交接

发布必须选择同一 `main` 提交、全部 27 个必需作业成功的完整 CI。任何缺项、跳过、失败、重复或未知作业均不能满足门禁，旧四作业结果及专项运行不能替代。附件中的 `ciRun` 为最终依据：`https://github.com/wybroot/alinksec/actions/runs/<ciRun>`。合并前的功能分支 CI 不能作为正式发布 CI。

已完成模块的软件实现与 CI 验收不外推现场覆盖。以下项目由用户后续验收，原始记录与结论须保留：

- 目标发行版／内核、UOS／麒麟、其他 Windows 版本的原生整机运行；容器用户态测试不证明宿主内核、systemd 或整套合规规则适用。
- 实际部署使用的私有／签名情报源与 OpenCTI、实际 WSUS 或公网源、指定补丁安装与真实重启。
- 200 台真实主机持续 72 小时及指标 1 秒目标；CI 的 200 个协议客户端／180 秒和近期指标查询不能替代。
- 历史 Windows ETW 丢事件与证据回执超时的持续稳定性观察。已修正并验证的观察句柄共享冲突不等于追认历史超时原因。

现场记录模板、证据入口及接手顺序见[发版准备与现场交付](../80-发版准备与现场交付.md)。本次正式发布已完成；生产部署尚未执行，仍需独立指示。
