# Windows 更新发现与自动修复

Windows 更新从“漏洞与修复 → Windows 更新”进入。操作员对在线 Windows Agent 发起发现，页面保留逐主机状态、适用更新及不可自动安装原因。尚未发现、旧 Agent、离线、发现失败和超过 24 小时的结果均不作为当前可安装证据。新发现开始后，旧发现立即退出审批范围；同一次发现只接受首份合法结果，重放不能改写目标。

## 安装与授权

使用系统 Windows Update Agent（WUA）接口和主机当前更新源，包括已有 WSUS；不注册新来源，不覆盖更新策略。安装对象为发现时的 UpdateID 与 RevisionNumber，固定主机安装身份、系统构建、版本类型、默认更新服务及更新源策略摘要，同时固定标题、KB 集合、下载上限和许可文本摘要。系统补丁修订 UBR 不进入稳定主机身份，以便更新后继续复核。

每台主机一次一项，最多 50 台；有待审批、安装或重启复核中的任务时不能创建另一任务。只有 WUA 声明为软件、安全或关键类别、许可已在本机接受、无需交互或安装源且最大下载不超过 4 GiB 的更新才可提交。超过容量上限的更新保留发现结果及不可安装原因，不影响同次发现的其他合格目标。当前不支持驱动、功能升级、其他更新类别和任意上传 MSU/EXE，也不从注册表软件名称、KB 显示名或 CVE 修复版本猜测补丁适用性。未接受许可的更新需先由主机管理员处理许可。

任务复用实际账号审批、维护窗口、持久排队与取消流程。只有指定且仍启用的管理员或操作员能审批；每次派发和离线重推重新核对账号权限、窗口、当前发现、能力与固定对象。单次派发起算最长 30 分钟，不因重推延长；窗口更早结束则以窗口为准。已送出的安装指令不能通过取消承诺撤回。

Agent 重新搜索精确更新身份并核对固定元数据。系统待重启、下载异常、磁盘余量不足、修订变化、目标已被替代、来源策略变化、安装器忙碌、无法静默安装或期限到达均不开始新安装。下载交由 WUA 校验内容，使用系统下载缓存；至少保留最大下载大小加 1 GiB 系统盘余量。使用静默、无安装源提示和非强制安装选项，不调用重启命令。

## 中断、重启与结果

在调用原生安装前，将任务、固定目标和安装意图写入私有、原子、同步落盘的恢复记录，并持有进程间锁。相同任务重放返回已记录结果；安装调用中断或结果不明时，恢复后只做已安装状态查询，禁止自动重新调用安装。原生更新服务可能在客户端超时后继续执行；不承诺撤销或自动回滚已经开始的安装。

原生整体与单项结果必须均成功，再查询同一 UpdateID 和修订的已安装状态。需要重启时记为“等待重启复核”，不记完成；原生安装明确要求重启时，保存启动时标识，即使系统待重启标记提前消失也须核实一次后续启动。Agent 心跳期间每分钟尝试有界只读恢复复核。原生查询失败或状态不明记为“安装状态待复核”，保留证据。离线恢复结果使用现有有界补传队列，并由服务端提交后的结果回执停止重复发送。

只有确切修订已安装且没有待重启条件时才记复核成功。Windows 更新结果不直接关闭 CVE 漏洞记录；软件漏洞仍须按当前漏洞规则重新评估。页面和通用任务记录均保留重启标记、复核状态和结构化原生证据。每项日志最多 8000 字符，证据最多 8192 字符；每次发现最多 256 个更新，单份快照最多约 2 MiB，Agent 私有恢复目录最多 1024 份记录，满时拒绝新安装，需人工归档已完成记录。

若目标被其他更新替代等原因使精确修订无法继续复核，创建人或指定审批人可以人工检查主机后填写处置说明并“结束复核”。此操作只结束平台跟踪，保留失败及原始证据，不中止后台安装，也不声明安装完成；Agent 收到认证关闭回执后停止该任务的查询和补传。已实际送出的任务允许接收晚到的精确安装证据，未送出或取消的任务不接收成功结果。

## 系统与验收边界

当前面向 Windows amd64、Windows PowerShell 5.1、可用的 WUA COM 与 CIM 服务，通常由 LocalSystem 或管理员运行。WUA 服务、签名、网络、策略和原生适用性判断失败均如实报告；不修改域策略、系统更新服务配置或其他安装器状态。系统自带更新编排可能与本任务竞争，安装前的忙碌检查无法承诺排除其他管理工具之后发起的安装。

验收包括便携执行状态机的中断、重放、损坏记录、容量、修订和重启边界；原生 Windows 检查实际 WUA 接口、默认来源身份、静默属性，以及生产 PowerShell 执行器在受控提供程序下的下载、安装、部分失败、许可和适用性分支。受控提供程序仅存在于测试文件，产品没有切换入口。CI 不对共享或用户主机安装真实系统更新；该验收不等于某个实际厂商补丁已在现场安装成功。真实 WSUS/公网更新与指定补丁安装仍须在相应环境验收。

SQLite/PostgreSQL 集成核对实际审批账号、持久指令、首份发现、非法回报、目标失效、离线重推和重启复核。生产前端使用这些数据库响应检查查看者、创建者、指定审批人、失败重试及桌面和手机页面。完整检查及产物验收结果在完成后补记。
