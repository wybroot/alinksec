# v0.0.4 文档核对与封版范围

本次按用户“所有文档”要求覆盖此前全部 91 份受 Git 管理的 Markdown 和 LICENSE，共 92 份文本资料，并新增文档索引、本核对表和 v0.0.4 发布说明。LICENSE 的 Apache 2.0 法律原文完整保留；基线参考 `.txt` 是检查输入，Web `index.html` 是应用入口，不作为产品文档改写。产品版本文件、Compose、Maven／npm 元数据与发布默认标签同步更新。

## 全量核对方法与实质修订

逐份记录原始路径、标题与摘要，扫描整份文本中的版本、规划、实现及验收陈述；核对本地链接、协议消息、迁移来源、运行配置和发布门禁。所有既有 Markdown 均更新本版适用或历史范围；核心文档另修正旧徽章、安装示例、升级步骤、集群描述、旧 DDL、过时路线和凭据处理，不能仅靠更换版本号推断能力。

当前 Command 为 14 种任务加 4 种回执／控制消息；数据库实际结构由源码与 V001～V036 定义；Redis／RabbitMQ 已在可选应用集群实现，普通部署不依赖二者；等保包、SCAP、上游更新、厂商公告、OpenCTI、来源冲突、引擎和报表各自遵循对应文档的边界。默认 Agent 不携带原生 YARA 运行时。
