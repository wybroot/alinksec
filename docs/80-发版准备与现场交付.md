## 接手顺序

1. 核对本次版本提交的完整 CI；所有 27 个必需作业均完成且成功，必须包含 Windows Server 2022／2025。版本、六份 Maven POM、Agent、前端及 Compose 默认镜像均为 `0.0.3`。
2. 从[正式 Release](https://github.com/wybroot/alinksec/releases/tag/v0.0.3)下载六个附件，按[版本发布流程](13-版本发布流程.md)核对校验和、三个组件的双架构镜像索引及实际平台 digest；已经发布的标签和附件不重复发布或替换。
3. 按[真机部署检查清单](../deploy/部署检查清单.md)选择 PostgreSQL 标准模式、SQLite 单机模式或[集群配置](../deploy/cluster/README.md)。记录环境信息后再进行配置与安装；凭据仅留在部署环境。
4. 先接入一台 Linux 和一台 Windows 目标主机，核对实际版本、mTLS、心跳、资产与目标功能。随后分批扩展系统范围、外部服务和长期负载，逐项保存下面的现场记录。

上述顺序是接手与现场执行计划；正式发布依据见前表，现场验收和生产部署仍须另行执行和记录。
