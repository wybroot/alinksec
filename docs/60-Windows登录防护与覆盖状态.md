# Windows 登录防护与覆盖状态

Windows 登录防护为独立规则 `PR-0004`，默认停用、仅告警。Linux SSH 规则 `PR-0003` 保持独立。Windows 规则必须明确设置 `platforms:["windows"]` 和 `windows_contract:1`；未知契约、混入 SSH 端口、非 3/10 登录类型和超限参数会被平台及 Agent 拒绝。

## 事件与适用范围

Agent 每 5 秒通过 Windows Event Log API 查询本机 Security 通道中 Microsoft-Windows-Security-Auditing 的 4624/4625 XML，按字段名解析，不依赖本地化消息。只累计有有效远程 IPv4/IPv6 来源的类型 3（网络登录）和类型 10（远程交互登录），排除缺失来源、回环、链路本地和特殊地址。IPv4 映射地址统一归一化。类型 3 可能来自 SMB 等网络认证，不能据此判定为 RDP。域控上的 Kerberos 专用事件、交互登录、缓存登录、外部身份源和无远程来源的认证不在此检测范围。

系统须启用“审核登录”成功/失败子类别，并允许服务身份读取 Security 日志和查询审计策略。Agent 尝试启用服务令牌已持有的 SeSecurityPrivilege，不修改审核策略或授予新权限。系统审核策略不能证明所有按用户覆盖或外部身份提供程序均完整。界面的“正在监测”表示最近读取成功且系统成功/失败审核开启，不代表没有攻击或所有登录均被审计。

首次启用从当前日志末尾建立基线，避免用旧日志自动封禁。单次最多读取 128 条事件，每条原生 XML 与最终 UTF-8 各不超过 64 KiB；查询句柄固定在创建的 OS 线程，并关闭所有原生句柄。读取故障、事件解析失败或顺序异常不会跳过事件推进游标。日志清空、覆盖或记录号复用通过原生记录锚点识别，产生覆盖缺口并开启新代际，旧失败计数不跨代累计。清空前已丢失的事件无法恢复。

## 检测、响应与恢复

失败次数按规则和来源 IP 在配置窗口内累计，账户按 `DOMAIN\\account` 不区分大小写完整匹配排除项；IP/CIDR 信任项支持 IPv4、IPv6。支持时区、跨午夜允许时段与成功登录的异常时段告警。成功登录始终仅告警。

封禁使用动态 WFP 会话，只限制该来源进入配置 TCP 端口，默认 3389，可按需配置 445 等端口。事件不提供服务端目标端口，所以这些端口是响应范围，不是事件所属服务的证明。封禁不修改现有防火墙配置、默认动作或其他管理员规则。管理服务 IP 被排除，管理域名解析失败时只上报封禁失败。动态过滤器在进程退出时由 Windows 撤销；运行期间由独立单调计时器按原到期时间撤销，不依赖事件读取循环。撤回规则、增加信任来源、修改端口或缩短有效时长会解除不再匹配的封禁。WFP 清理失败会报告故障并让 Agent 主循环退出，由原生服务恢复配置重启以清理动态对象。

游标、代际、窗口计数、封禁意图和待确认告警保存在限制为 SYSTEM/Administrators 的目录内，原子落盘后才安装过滤器。状态文件上限 1 MiB，最多 128 个来源窗口、每窗口 100 次失败、128 条封禁、64 条未确认告警。状态损坏会明确失败；不会把坏状态当作空状态继续执行。重启恢复尚未到期且仍符合当前规则的封禁，保留原到期时间。

告警具有代际/记录号/规则确定的稳定身份。服务端在同一事务内写入永久回执与告警，提交后才通过当前认证通道发送回执。Agent 收到并持久化回执后删除本地告警；断线、服务端失败或回执丢失会重发，在线未确认事件每 30 秒重试。缓冲区满时保留已提交记录，在事件边界停止推进游标，显示等待平台回执，避免无界磁盘增长。长期失联期间原始 Security 日志仍可能被覆盖，这会显示日志缺口。平台回执按主机和事件去重，10 分钟传输去重窗口过后仍不重复累计告警。

## 平台状态与验证

心跳携带 Windows 登录执行契约和有界覆盖 JSON。平台按主机显示正在监测、追赶、审核未开启、读取/保存/封禁失败、日志缺口、旧版不支持、离线、过期和采集停滞。策略保存或同步 ACK 只证明配置接收；实际状态以主机覆盖信息为准。当前封禁数仅展示有效的近期状态。状态接口按 Windows 主机分页，最多每页 100 条；只读角色不能修改规则。

本模块的自动验证包含跨平台 XML/状态机测试、原生 Windows Security 4625 与审核查询、WFP 双栈过滤器、独立到期和进程退出清理、双数据库事务与回执去重，以及桌面/手机页面配置和失败重试。Windows CI 在其提供的 Windows 系统上执行；其他 Windows 版本和真实远程 RDP/SMB 客户端仍需现场验收。原生同机网卡 TCP 探测单独报告是否可用，不将内核本机回环旁路当作远程拦截证据。
