# 复查控制台与分页补证

日期：2026-11-22。基线为已验收主线 `faa4990`；分支 `test/review-console-boundaries` 只补齐 REV-005／006／007／008 的关闭证据，产品目标仍为 v0.0.4。本文在精确提交完整 CI 和原始归档核对前保留这四项 VERIFY；当前为 7 项 CLOSED、7 项 VERIFY。

## 场景与证据来源

测试启动器 `server/alinksec-bootstrap/src/test/java/review/console/ConsoleAcceptance.java` 使用生产 Spring 应用，向随机回环端口发送真实 HTTP 请求，经生产鉴权、控制器、服务及审计路径处理；它只进入测试类路径，不进入生产 jar，也不添加产品接口。两类数据库分别使用全新私有 SQLite 文件、按跟踪 SQL／迁移初始化的独立 PostgreSQL 与受限应用角色。分页记录是明确标记的数据库夹具，不声称由原生 Agent 采集。

- REV-005：管理员原密码错误后会话仍可用，首次改密成功后两个旧会话被拒绝；旧密码登录失败、新密码成功。实际创建 viewer、提升 operator、禁用、重新启用并重置密码，检查版本及旧会话撤销。viewer 创建／编辑他人账号被拒绝且 SQL 状态不变；自助改密忽略请求中伪造的他人身份，撤销自身两个旧会话，新密码重新登录，管理员状态保持原样。检查完整审计行、操作期间实际应用日志事件及完整容器日志是否包含所有提交密码、实际令牌和存储密码哈希；不归档比较用的私密值。
- REV-006：105 条告警按实际 REST 分两页读取，最早待处理告警位于第二页；服务端严重、高危及待处置筛选分别取得真实结果。页面回放这些捕获响应，检查第二页、筛选、处理后清空、真实空列表、模拟网络失败与重试，以及延迟旧响应不覆盖新筛选。
- REV-007：viewer 实际接口标记返回 403；管理员首次标记成功，重复和不存在记录返回原业务拒绝。独立 SQL 确认终态处置人、备注及时间未被覆盖，指令表前后均为空。页面验证“已标记处理；未下发主机动作”、重复拒绝和模拟标记请求网络失败提示，viewer 不显示写入按钮。此操作只标记数据库状态，原条件中“若支持实际处置”的主机动作回执不适用于本入口。
- REV-008：告警、漏洞、病毒、审计和软件五类实际 REST 入口，对 admin／operator／viewer 逐一发送 18 种非法参数，包括负数、零、32／64 位边界、超长整数、offset 溢出及 pageSize／limit 别名。审计的两个低权限角色在参数校验前返回 403，其余非法请求返回 400。允许访问的组合另验证正常前两页、最大整数 size 被收敛到入口上限及合法大 offset 空结果；遍历正常分页，以独立 SQL 标识集合验证无重复或遗漏。软件接口保留原数组结构和 500 上限，其余四类保留 list／total 与 100 上限。

`deploy/tests/review-console-verdict.py` 从原始逐请求响应、SQL 事实、审计行、日志摘要与页面响应绑定重新检查结论，未只采信验收汇总布尔值。生产包浏览器在 CI 执行；本机按内存限制只构建当前页面、布局和登录路由的预览，结果明确标注 `current-source-routed-preview`，不能代替 CI 的 `production-bundle`。

## 资源和验收边界

本地两个数据库场景各完成 459 次真实 HTTP 请求和 13 项页面检查，原始记录经独立脚本复核；它们标记为未提交工作树和页面预览范围，不充当提交后的完整软件验收。页面夹具曾遇到消息提示定位冲突、隐藏 switch 输入框无法点击，以及单进程 Chromium 在关闭最后一个 context 后不能复用的问题；失败日志保留，调整测试定位与串行启动浏览器后全程通过，未通过放宽产品断言消除失败。

本机串行构建及执行场景。Java 容器上限 640 MiB、堆 256 MiB、一个 CPU；PostgreSQL 场景另用 256 MiB，启动前检查可用内存。运行时低于 384 MiB 可用内存或 full PSI 超过 10% 即停止。后端容器退出、检查非 OOM 并清理后，才构建预览／运行浏览器；保留原有用户服务及数据卷。

浏览器只回放已脱敏的真实 HTTP 响应，网络故障和乱序由浏览器显式注入；这不描述为浏览器直接连接存活的后端。真正的密码验证、角色拒绝、数据库更新和会话撤销由前述真实后端请求记录证明，页面中的提交值是独立占位值。私密数据库、证书、原始密码／令牌和比较清单全部在结束时销毁；归档只保留脱敏响应、无凭据日志与 SQL 事实。

55 项 BKL 保留原状态；现场 25／26／27 继续延期，28 对当前全新部署范围仍为 N/A。本批不执行版本发布或生产部署。
