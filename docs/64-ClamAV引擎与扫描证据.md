# ClamAV 引擎与扫描证据

ClamAV 为可选的本机外部引擎。Linux amd64、Linux arm64 和 Windows amd64
Agent 使用 INSTREAM 将文件内容交给管理员维护的 ClamAV 服务；内置 SHA256
和内部规则保持独立。默认不启用、不下载特征库，也不启动或安装系统服务。

## 部署与信任边界

安装受支持并已修复安全问题的 ClamAV，加载来自可信来源的特征库，按官方流程维护
`freshclam`。本模块原生验收固定为官方 1.4.6；正式环境的更新与容量由管理员管理。
完整官方特征库的内存需求明显高于本项目约 2 GiB 的开发机，不能根据小型测试库的
结果推算正式库资源需求。[安装说明](https://docs.clamav.net/manual/Installing/Docker.html)

`clamd` 的 TCP 协议没有认证或 TLS。Agent 要求前置 TLS 服务，只连接本机字面量
回环 IP，固定前置服务的叶证书 DER SHA256，并校验证书有效期、服务用途和 TLS
版本。证书私钥、前置服务配置、ClamAV 程序、库、配置和后端通道必须由管理员保护。
Linux 推荐前置服务连接权限收紧的 Unix socket；Windows 后端回环 TCP 还需通过本机
服务权限和网络访问控制防止低权限进程访问或冒充后端。仅给一个普通 TCP 端口套上
TLS 并不能认证端口后面的 `clamd`，管理员必须保障整条本机通道。
[ClamD 说明](https://docs.clamav.net/manual/Usage/Scanning.html)

例如，可将管理员部署的 stunnel 服务配置为仅监听 `127.0.0.1:3311`，证书及私钥由
服务账号独占读权限；Linux 连接私有的 `clamd` Unix socket。前置服务不能允许客户端
选择任意后端。不要开放原始 `clamd` 或前置端口到公网，也不要将通道转发到远程主机。
Agent 没有不校验证书或回退明文的选项。

在受配置防篡改保护的 `agent.yml` 中添加并按可信配置恢复流程批准，然后重启 Agent：

```yaml
clamav:
  enabled: true
  address: 127.0.0.1:3311
  server_cert_sha256: '<叶证书 DER 的 64 位十六进制 SHA256>'
  realtime: false
  timeout_sec: 10
```

证书摘要可通过 `openssl x509 -in server.crt -outform DER | openssl dgst -sha256`
取得；不要将冒号分隔的指纹、私钥或证书 PEM 填入该字段。Agent 只在本机保存连接
地址与证书摘要，心跳和控制台不返回它们。证书轮换必须同步批准本机配置，失败时不
降级到其他证书或明文连接。平台策略不能替换该地址或证书。

管理员应为 `clamd` 设置有限的 `MaxThreads`、`MaxQueue`、`StreamMaxLength`、
`MaxFileSize`、`MaxScanSize`、`MaxRecursion`、`MaxFiles`、`MaxScanTime` 和字节码
预算，并启用 `AlertExceedsMax yes`、`AlertEncrypted yes`，使超限或加密内容能够
显式报告未完整检查。源文件最大 20 MiB，`StreamMaxLength` 应至少为 20M。
前置服务应有连接数、握手、读写超时和资源限制；中断 Agent 连接不保证 `clamd`
立即取消解析，仍需由守护进程自身约束工作量。Agent 无法通过扫描协议读取或认证
全部守护进程配置。管理员调整这些配置会改变实际覆盖范围。

## 使用与结果

病毒页显示每台主机最近报告的就绪状态、引擎版本、实时选项、尝试数、失败数和最近
错误。主机离线、旧 Agent、90 秒未更新的心跳或探测不能作为当前就绪状态。30 秒
探测只说明协议和版本可访问，不证明特征库完整、足够新或所有文件都经过检查。

主动扫描在对话框明确选择“内置特征库”或“ClamAV”。默认内置；每台主机在任务
创建时固定其 ClamAV 报告版本，投递时重新检查。ClamAV 命令使用执行契约 3，旧
Agent 会拒绝，不会误按内置引擎执行。内置命令和已有文件处置仍使用契约 2。
同一任务可包含报告版本不同的主机，各主机证据分别保留固定版本和执行版本。

ClamAV 每个文件扫描前后都检查 `VERSION`，发生变化或响应无效则该文件无 ClamAV
检出。`VERSION` 是守护进程报告的标识，**不是完整特征库摘要**，尤其自定义数据库
变化可能不改变该标识；任务无法证明全部定义在整个扫描期间字节不变。需要更严格
的可复现性时，管理员应在维护窗口固定整套服务和定义，暂停更新后执行任务。

Agent 对同一安全打开的普通文件描述符同时计算 SHA256、读取规则头和发送内容。
源文件读取完成后核验文件身份、大小和修改时间，隔离再核对该摘要；修改后的新内容
不会因旧判定被隔离。ClamAV 不接收源文件路径，也不执行隔离、删除或恢复。
隔离使用现有独立对象编号与逐文件回执，恢复校验原始字节和父目录身份。

主动任务共享现有 2 小时、10 万文件、20 GiB 读取上限和路径边界，ClamAV 单文件
源内容限制为 20 MiB；每次扫描（含等待串行门、版本探测和 TLS 连接）默认 10 秒，
本机可设置 1–30 秒。所有主动和实时 ClamAV 扫描共用一个串行门。超限文件计入
未完成，连接失败、超时、未知响应、版本变化以及 `Heuristics.Limits.Exceeded*` /
`Heuristics.Encrypted*` 不会被当作恶意软件自动隔离。压缩内容解析由 ClamAV 负责，
受其本机限制影响；源文件提交成功和零检出均不表示内容安全。
[流协议](https://docs.clamav.net/manual/Usage/ClamdProtocol.html)

本机 `realtime: true` 与平台周期病毒策略同时启用时，文件事件及有界补查会调用
ClamAV，沿用平台告警/隔离选项与路径/哈希白名单。实时单次总预算仍为 2 秒和
20 MiB；内置引擎可独立检测，ClamAV 不可用不会主动关闭它，但消耗完本次预算的
文件可能未覆盖，应结合引擎失败与文件监听状态判断。实时检出事件保留引擎及版本。
该能力为事件后的检测，不阻止文件在检查前被访问或执行。

## 验证范围

`deploy/tests/clamav-install.py` 校验官方发布资产 SHA256，仅解包到测试目录，不安装
系统服务。三平台原生测试启动私有 `clamd`，使用无害自定义 NDB 和一次性测试 TLS
前置连接，覆盖普通文件、压缩包展开、干净文件、真实解包上限、隔离恢复和原生文件
事件到告警。测试前置只属于测试代码，不是生产部署工具。

协议测试覆盖错误证书、取消等待、串行限制、畸形/超长响应、扫描错误、版本变化、
白名单和判定后内容替换。SQLite/PostgreSQL 验证状态与任务证据边界，浏览器使用
数据库捕获的响应验证桌面/手机状态、明确引擎选择、只读权限及错误重试。
完整官方库的检测效果、容量、长期性能、FreshClam 在线更新和现场私有服务配置
不属于小型测试库验收结论。ClamAV 由管理员独立安装并遵循其 GPLv2 许可。
