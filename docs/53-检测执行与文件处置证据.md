# 检测执行与文件处置证据

> 版本基线：v0.0.4。已按本版核对「检测执行与文件处置证据」的操作、实现引用与适用边界；历史日期及验证结果仍只对应其原始提交。版本差异见[发布说明](releases/v0.0.4.md)，全部资料见[文档索引](README.md)。

当前模块完善已有纯 Go SHA256 和内部 JSON 规则引擎，使用检测执行契约 2。旧 Agent 心跳未声明该契约时，平台拒绝新扫描和远程文件操作；旧记录保留，缺少隔离对象编号的旧隔离需要本机复核。来源治理、检测、部署仍在独立分支按顺序完成，不合并、不发布、不更新现有用户服务。

## 扫描范围和预算

| 项目 | 当前范围 |
|---|---|
| 主动扫描 | 快速、本机盘根、自定义1至64条绝对路径；每任务1至500台同路径适用的目标，Windows只接受本地盘符，按系统分组 |
| 每主机预算 | 最多2小时、100000普通文件、20 GiB源字节、400000访问条目、64层目录、1000检出；目录分批读取，错误细节最多32条 |
| 文件读取 | 普通文件不超过500 MiB；同一打开描述符产生SHA256与前2 MiB规则输入，读取前后复核大小/mtime/身份；源读取限速10 MiB/s，隔离验证与复制额外读写不计入源字节预算 |
| 内部规则 | strings text/hex、all/any、平台、扩展和1至50 MiB对象范围；先哈希命中否则规则首个命中，不是原生YARA语言/解析器；不解包压缩文件 |
| 排除 | 符号链接、特殊文件、虚拟/容器状态、Agent工作目录和自身可执行文件、白名单；Linux快扫单独允许/dev/shm，盘根不下降/dev |
| 特征包 | ZIP最多20 MiB，展开总量64 MiB、hash最多250000、规则JSON最多2 MiB/2000条，严格校验目录项、计数、摘要/模式/严重度；失败保留旧库 |

文件元数据缓存不再绕过主动扫描的字节读取。任务固定当前发布版本，离线重放时重新核对发布版本、操作账号和执行期限。未安装、损坏或空库明确失败。COMPLETE表示本次声明范围结束，仍可能包含超限、白名单等跳过；读取错误/预算耗尽返回PARTIAL或FAILED。零检出、空目录完成及进度100%均不证明整机安全。

平台先记录目标成员，只有成员的第一份有效结果能落库。每主机保留状态、计数、版本、错误、原始protobuf和SHA256，重传不得覆盖首次证据；进度按终态成员数计算。迟到回报保留并标记，不重新打开超时任务。扫描/周期报告去重与业务写入在同一事务，失败可重传；相同报告ID按已认证主机隔离。每周快扫按500台批次覆盖支持契约的在线主机。

## 文件操作与恢复

自动检出先记录路径与SHA256，再打开并重新核对同一文件。隔离使用随机32位十六进制对象ID，保存原路径、摘要、父目录身份及元数据；不上传样本。仅支持同卷捕获，跨卷rename失败保留原文件并报告处置失败；不伪装已隔离。捕获复制成Agent拥有的新对象，使原写入者持有的描述符不能改动已存样本；存储验证失败按原名未占用原则尝试回退，无法回退时保留对象ID供复核。

删除已有隔离对象只触碰该ID及匹配摘要，不会删除原路径新出现的替代文件。没有对象ID时先捕获，再删除；未完成捕获/删除的回执保留对象ID。恢复核对摘要与原父目录身份，原路径占用/父目录被替换则失败，不覆盖、不重建父目录。

Linux要求工作目录链属于Agent运行UID且其他用户不可写，隔离目录0700、载荷0400；恢复普通权限和UID/GID，不恢复SUID/SGID，不承诺扩展属性/ACL/安全标签。Windows使用拒绝重解析点的相对父目录句柄和无覆盖移动；专用Agent状态目录设置受保护继承DACL，只授权SYSTEM、管理员和当前运行账户。恢复原owner/group/有效DACL并保护DACL，后续父目录ACL继承变化不会自动应用；运行账户缺少原owner/ACL写入权限时明确失败，不扩大权限继续恢复。安装目录及其父目录需要由可信管理员控制，无法抵御管理员、内核或同权限Agent身份篡改。

人工操作一次最多32项、命令有效期15分钟、Agent批次预算30秒；底层文件系统调用阻塞时，超时返回可能延迟。当前数据库账号必须有效且为admin/operator；离线重放时再检查。请求和逐目标原始回执永久保留，只有成功目标更新已确认物理状态。失败/超时保留上次确认状态，可能已经有部分本机操作；不能据此推断文件仍在原位。断电、元数据提交或清理失败可能留下需要本机复核的对象，当前不提供自动灾后状态协调。平台可显示待确认、失败、首次检出和原始操作身份，旧路径单参数Agent API拒绝破坏性动作。

## 周期防护和白名单

平台独立保存启用/关闭和仅告警/检出后隔离策略；Agent持久化后执行，旧策略快照不再重放。当前 Agent 通过 Linux inotify / Windows ReadDirectoryChangesW 文件事件触发检查，周期及丢失后的恢复遍历保留进度。旧 Agent 仍可能只支持10秒快照。监听范围、数量、读取预算和独立覆盖状态见[事件驱动实时监控](63-事件驱动实时监控与覆盖状态.md)；事件不是写入完成或全文件覆盖证明。

白名单最多1000条，哈希按内容放行，路径按目录边界放行；拒绝相对路径、点段、整盘及Windows替代数据流。移除后恢复检测，加白不覆盖检出历史、不自动恢复隔离文件。恢复的同一内容未加白时，下一次扫描或周期变化检测仍可能检出。离线Agent及旧Agent不能由“策略已保存”推断已切换；只读角色可审查证据。

## 验证要求

本地按384 MiB最低可用内存、256 MiB语言堆、单worker和full PSI10% watchdog串行执行；前端仅构建页面预览，生产web-dist由CI提供。本地Java整组135项、补充边界30项、Go检测/guard/通信、Windows交叉编译及7项数据库生命周期页面场景已通过。Ubuntu22.04缓存镜像上的真实Agent验证已通过TLS库下载、部分覆盖、隔离ID删除保留替代文件、拒绝覆盖恢复、内容与权限恢复、跨卷失败、白名单及独立周期告警；CI使用Ubuntu24.04测试镜像。

正式验收还要求SQLite/PostgreSQL事务与迁移、Linux amd64/arm64 race测试、Windows原生文件API/ACL与服务、生产页面及手机只读证据全部通过。交叉编译只证明可编译；完整CI提交、下载产物、摘要核对及人工截图审查随PR单独归档，不能用本地预览代替生产产物验收。
