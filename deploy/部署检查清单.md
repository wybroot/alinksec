# ALinkSec M1 部署检查清单

> 架构：**服务端全家桶 Docker 部署**（PostgreSQL 17 + 服务端 + 前端），**Agent 裸装**（install + systemd，沿用原设计）。
> 按顺序执行，每步附验证命令/SQL。前置要求：服务器已装 Docker + docker compose v2；目标主机为 Linux。

---

## 0. 上传发布物到服务器

**先在本机准备**（Windows PowerShell，仓库根目录）：

```powershell
# 确认服务端 jar 是最新的
cd server; mvn -q -DskipTests clean package; cd ..

# Agent 交叉编译（目标主机 Linux amd64）
cd agent
$env:GOOS="linux"; $env:GOARCH="amd64"
go build -o alinksec-agent ./cmd/agent
$env:GOOS=""; $env:GOARCH=""
cd ..

# 打服务端发布包（jar + 前端源码 + 部署物；Agent 二进制单独传目标主机）
# 前端为 Vue3 工程（web/），镜像构建时容器内自行 npm ci + build，
# 本地只需上传源码（排除 node_modules/ 与 dist/，见下方 robocopy）
$items = @(
  "server\alinksec-bootstrap\target\alinksec-bootstrap-0.1.0-SNAPSHOT.jar",
  "deploy"
)
foreach ($i in $items) { New-Item -ItemType Directory -Force -Path "release\$i" | Out-Null }
foreach ($i in $items) {
  $dest = "release\$i"
  if (Test-Path $i -PathType Leaf) { Copy-Item $i $dest }
  else { Copy-Item "$i\*" $dest -Recurse -Force }
}
New-Item -ItemType Directory -Force -Path "release\web" | Out-Null
robocopy web release\web /E /XD node_modules dist | Out-Null
Compress-Archive -Path release\* -DestinationPath alinksec-m1.zip -Force
# 产物：仓库根下 alinksec-m1.zip
```

上传到服务器后解压（保持以下结构，`deploy/docker` 的构建上下文依赖仓库根层级）：

```
~/alinksec/
├── server/          (服务端 Maven 源码，Docker 构建阶段会生成 jar)
├── web/             (Vue3 前端源码：src/ public/ package.json …)
└── deploy/
    ├── sql/001_init.sql
    └── docker/      (Dockerfile.server/web + docker-compose.yml + nginx.conf + .env.example)
```

```bash
# 服务器上解压
mkdir -p ~/alinksec && cd ~/alinksec
unzip ~/alinksec-m1.zip
ls server/ deploy/docker/    # 确认文件就位
```

## 1. 配置 .env（首次启动前必做）

```bash
cd ~/alinksec/deploy/docker
cp .env.example .env
vim .env     # 把 HOST_IP 改成服务器真实 IP
# 同时设置 ALINKSEC_BOOTSTRAP_ADMIN_PASSWORD（至少 12 位）和
# ALINKSEC_BOOTSTRAP_ENROLL_TOKEN（随机 ENROLL- 前缀字符串）
```

> **为什么重要**：服务端证书只在**首次启动**生成一次，SAN 默认不含服务器 IP。
> 目标主机 Agent 通过 `<IP>:9443` 连接时 TLS 校验会失败。忘改的补救见 §6 排障表。

---

## 2. 构建镜像 + 启动 PG

```bash
cd ~/alinksec/deploy/docker
docker compose build               # 构建 server + web 两个镜像
docker compose up -d postgres      # 先只起 PG
docker compose ps                  # 期望 postgres 为 (healthy)
```

**验证 ①：容器健康 + 建表成功**

```bash
docker exec alinksec-pg pg_isready -U alinksec -d alinksec
# 期望：accepting connections

docker exec -it alinksec-pg psql -U alinksec -d alinksec -c "\dt"
# 期望 9 张表：t_agent t_alert t_asset_account t_asset_port t_asset_software
#            t_command t_enroll_token t_host_group t_report_dedup
```

> 若表缺失：`docker logs alinksec-pg` 查初始化日志；
> 初始化仅执行 `001_init.sql`，且只适用于空数据库；如执行中断，应重建数据库卷后重新初始化。

---

## 3. 启动服务端 + 前端

```bash
docker compose up -d server web
docker compose ps       # 期望 alinksec-server / alinksec-web 均 running
```

**验证 ②：服务端启动成功**

```bash
docker compose logs server | grep -E "gRPC|Bootstrap"
# 期望出现：
#   gRPC 服务已启动: port=9443 (mTLS)
#   Bootstrap administrator created: admin
```

> 启动前在 `.env` 设置 `ALINKSEC_BOOTSTRAP_ADMIN_PASSWORD`（至少 12 位）及随机的
> `ALINKSEC_BOOTSTRAP_ENROLL_TOKEN`。这两个敏感值不会写入日志。

**验证 ③：端口监听**

```bash
ss -tlnp | grep -E '9443|8080|8081'    # 期望三行 LISTEN
```

**验证 ④：证书已生成（volume 内）**

```bash
docker exec alinksec-server ls /app/data/certs
# 期望：ca.crt ca.key server.crt server.key
```

**验证 ⑤：前端可访问**

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8081/
# 期望：200
```

浏览器打开 `http://<服务器IP>:8081/`（安全控制台）和 `http://<服务器IP>:8081/screen`（安全大屏）。
> 前端为 Vue3 + Vite + Element Plus + ECharts 正式工程（源码 `web/`），M1 数据为前端内置模拟（`web/src/api/index.js`）；接真实 Agent 数据在 M2 REST API 完成后联调。

> 防火墙放行：`firewall-cmd --permanent --add-port=9443/tcp --add-port=8081/tcp && firewall-cmd --reload`
> （Ubuntu/ufw：`ufw allow 9443/tcp && ufw allow 8081/tcp`）

## 4. 目标主机安装 Agent（裸装，沿用原设计）

上传 `agent/alinksec-agent`（本机交叉编译产物，见 §0）到目标主机 `/usr/local/bin/`。

**验证 ⑥：安装 + 注册 + 证书落盘**

```bash
chmod +x /usr/local/bin/alinksec-agent
sudo /usr/local/bin/alinksec-agent install \
  --server <服务器IP>:9443 \
  --token <ALINKSEC_BOOTSTRAP_ENROLL_TOKEN> \
  --ca-file /path/to/alinksec-ca.crt

# 期望输出：
#   安装完成：agent_id=xxxxxxxx-xxxx-...
#   配置: /var/lib/alinksec-agent/agent.yml

sudo ls /var/lib/alinksec-agent/
# 期望：agent.yml  ca.crt  client.crt  client.key  state.yml
```

**验证 ⑦：前台跑通主通道**

```bash
sudo /usr/local/bin/alinksec-agent run
# 期望日志：
#   agent 启动 agent_id=... server=<IP>:9443
#   主通道已建立 agent_id=...
#   策略已同步 policy_version=v0
# Ctrl+C 停掉，进下一步常驻
```

**验证 ⑧：systemd 常驻**

```bash
sudo tee /etc/systemd/system/alinksec-agent.service <<'EOF'
[Unit]
Description=ALinkSec Agent
After=network-online.target

[Service]
ExecStart=/usr/local/bin/alinksec-agent run
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable --now alinksec-agent
systemctl status alinksec-agent    # 期望 active (running)
```

## 5. 端到端验证 SQL（回服务器执行）

统一用以下方式连 PG（5432 未暴露宿主机，只能 exec）：

```bash
alias psqla='docker exec -it alinksec-pg psql -U alinksec -d alinksec'
```

### 验证 ⑨：注册落库

```sql
SELECT agent_id, hostname, ip, os_type, arch, status FROM t_agent;
```
期望：1 行，`status=0`（待激活），hostname/ip 为目标主机真实值。

### 验证 ⑩：心跳在线

```sql
SELECT agent_id, status, agent_version, policy_version, last_heartbeat,
       now() - last_heartbeat AS age FROM t_agent;
```
期望：`status=1`（在线），`age` < 10 秒且隔一分钟再查持续刷新。

### 验证 ⑪：策略同步指令闭环（M1 核心链路）

```sql
SELECT cmd_id, type, status, result FROM t_command ORDER BY id DESC LIMIT 5;
```
期望：`type=policy_sync`，`status=4`（已完成），`result` 含 `"code":0`。
同时 `t_agent.policy_version=v0`，且后续心跳不再新增指令（版本已一致）。

### 验证 ⑫：注册码核销 + 上报幂等

```sql
SELECT token, used_count, max_uses, status FROM t_enroll_token;  -- used_count=1
SELECT count(*) FROM t_report_dedup;                              -- > 0
```

### 验证 ⑬：离线检测（可选）

```bash
# 目标主机
sudo systemctl stop alinksec-agent
```
等 90 秒（阈值 60s + 扫描周期 30s）后：

```sql
SELECT agent_id, status FROM t_agent;   -- 期望 status=2（离线）
```

```bash
sudo systemctl start alinksec-agent     # 30 秒内恢复 status=1
```

## 6. 常见问题排查

| 现象 | 原因 | 处置 |
|---|---|---|
| Agent 报 TLS 证书错误（x509/SAN 不含 IP） | .env 的 HOST_IP 没在首次启动前配好 | `docker compose down server && docker volume rm alinksec_server-data && docker compose up -d server`（CA 重签，已装 Agent 需重装） |
| Agent 报 `token 无效` (20001) | 注册码抄错/过期 | `docker compose logs server \| grep ENROLL` 重取；或查 `t_enroll_token` |
| Agent 报 `20003 该主机已注册` | machine_id 重复（重装系统不变） | `psqla -c "DELETE FROM t_agent WHERE machine_id='<该机>';"` 后重装；或删目标机 `/var/lib/alinksec-agent/` 换新注册码重装 |
| server 容器反复重启：Connection refused | PG 未 healthy 就被依赖/密码不符 | `docker compose ps` 看 PG 状态；核对 compose 里 PG_PASSWORD |
| 注册成功但主通道连不上 | 9443 未放行 | 防火墙放行；服务器 `ss -tlnp \| grep 9443` |
| `docker compose build` 失败：找不到 jar | 上传时丢了 target 目录 | 确认 `server/alinksec-bootstrap/target/*.jar` 存在（§0 结构） |
| t_agent 一直 status=0 | Agent 未 run（只 install 了） | `systemctl status alinksec-agent`；`journalctl -u alinksec-agent -f` 看日志 |
| t_command 有行但 status 一直 0 | Agent 在线但未收到指令 | 确认 Agent 活着且服务端日志无 `指令写入失败` |
| 前端 8081 打不开 | 防火墙/端口被占 | `curl 127.0.0.1:8081` 本机测；改 compose 端口映射 |

**日志速查**

| 组件 | 命令/位置 |
|---|---|
| 服务端 | `docker compose logs -f server` |
| PostgreSQL | `docker compose logs postgres` |
| 前端 nginx | `docker compose logs web` |
| Agent（目标主机） | `journalctl -u alinksec-agent -f` |
